Code là gì? Lập trình là gì?

Code (hay mã nguồn) hiểu một cách đơn giản nhất chính là ngôn ngữ dùng để giao tiếp với máy tính.

Code hoạt động như thế nào?

Code hoạt động như thế nào?

Bản chất của việc viết code (lập trình) giống như việc bạn viết một cuốn sách hướng dẫn từng bước một.

Ví dụ nút "Gửi" tin nhắn đằng sau nó là những dòng code đang ra lệnh cho máy tính:

  1. Kiểm tra xem người dùng đã nhập chữ chưa.
  2. Nếu có, hãy đóng gói tin nhắn đó lại.
  3. Gửi nó qua internet đến bạn bè.
  4. Hiển thị thông báo đã gửi.

Các loại ngôn ngữ phổ biến hiện nay

Tùy vào mục đích bạn muốn máy tính làm gì, bạn sẽ dùng loại ngôn ngữ (loại code) đó:

  • HTML/CSS/JavaScript: Dùng để tạo ra các trang web bạn lướt qua hàng ngày.
  • Python: Rất phổ biến trong việc làm trí tuệ nhân tạo (AI), phân tích dữ liệu, hoặc cho người mới bắt đầu vì nó dễ đọc như tiếng Anh.
  • Java / Kotlin / Swift: Dùng để viết các ứng dụng chạy trên điện thoại Android hoặc iPhone.
  • C++ / C#: Thường được dùng để viết các phần mềm nặng hoặc thiết kế game đồ họa cao.

Tóm lại, nếu coi máy tính là một người nước ngoài, thì "code" chính là thứ tiếng nước ngoài mà bạn học để hướng dẫn và làm việc cùng họ.
